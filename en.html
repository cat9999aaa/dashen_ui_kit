// HOW TO USE

Install, import, initialize

This site explains the repository as a product: how to run it, import its API, install the skill, and build your own theme.

terminalBASH
git clone https://github.com/cat9999aaa/dashen_ui_kit.git
cd dashen_ui_kit
bun install
bun run dev
bun run check
app.tsTYPESCRIPT
import "dashen-ui-kit/styles.css";
import { initExoframeUI, palettes, getPalette } from "dashen-ui-kit";

initExoframeUI();
console.log(palettes.length, getPalette("amethyst"));

Package the UI as a reusable skill

The skill ships with design rules, module map, HTML PPT workflow, and local templates.

# installs $exoframe-ui into local Codex skills
  • Local assets and no-CDN rules
  • Palette module migration order
  • HTML PPT instead of .pptx
  • ASCII, print, and mobile QA checks
// BUILD YOUR THEME

Create your own visual shell

Add one palette file and one manifest entry. Do not rewrite components.

src/styles/tokens/palettes/11-your-theme.cssCSS
[data-palette="your-theme"] {
  --palette-bg: #07090f;
  --palette-surface: #101522;
  --palette-primary: #7cf7ff;
  --palette-success: #8cff5a;
  --palette-signal: #ffd166;
  --palette-danger: #ff4f6d;
}
