import "dashen-ui-kit/styles.css";

initExoframeUI();

// CODEX SKILL

把这套 UI 变成别人可调用的 skill

skill 已包含设计规则、模块地图、HTML PPT 工作流和模板。它可以教 Codex 用 EXOFRAME 构建界面、文档和演示稿。

terminalBASH
bun run skill:install
# installs $exoframe-ui into local Codex skills
  • 本地资产与无 CDN 规则
  • palette 模块化迁移顺序
  • HTML PPT，而不是 .pptx
  • ASCII 对齐、打印和移动端检查
// BUILD YOUR THEME

构建自己的主题

新增主题只加 palette 文件和 manifest，不碰组件。这个约束让组件库未来能被别人安全复用。

src/styles/tokens/palettes/11-your-theme.cssCSS
[data-palette="your-theme"] {
  --palette-bg: #07090f;
  --palette-surface: #101522;
  --palette-primary: #7cf7ff;
  --palette-success: #8cff5a;
  --palette-signal: #ffd166;
  --palette-danger: #ff4f6d;
}
