# EXOFRAME Design Rules

- Use original terminal, CRT, ASCII, instrumentation, and print-system language.
- Do not use franchise IP, organization names, character names, copied logos, or copied interface graphics.
- Use local assets only.
- Keep files small and layer-specific.
- Keep base/system styling separate from palette modules.
- Never add component selectors to palette files.
- Use semantic variables in components and elements instead of hard-coded palette colors.
- Treat article and print output as first-class surfaces.
- Respect reduced motion.
- Prefer token-driven styling over hard-coded component colors.
